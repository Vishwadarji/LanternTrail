# Android debug build

LanternTrail-debug.apk is the signed debug APK for Vishwa Darji’s Lantern Trail project. It supports Android 8.0 (API 26) and newer. It was exercised on two Android 15 phone emulators.

For Android Studio, open the repository root and run the app configuration. For installation on a phone, transfer the APK and use Android’s standard installation flow. This is a class demonstration build, not a Play Store release.
